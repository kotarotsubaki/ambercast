# Simplified Chinese style reference

两个独立来源，各自在引用规则旁边注明出处与许可证。

## 阮一峰《中文技术文档的写作规范》

出处：https://github.com/ruanyf/document-style-guide （公共领域，public domain）。

- 全角中文字符与半角英文字符之间应有一个半角空格；与半角阿拉伯数字之间，加不加空格均可，但必须全文统一，不可两种风格混用。
- 避免使用长句；逗号分隔的句子构件应保持简短，意思不明确的长句必须拆分。
- 同一个意思尽量使用肯定句表达，避免使用否定句或双重否定句。
- 不使用非正式的语言风格，不使用冷僻、生造或文言文词语。
- 尽量使用主动语态，不使用被动语态。

## sparanoid《中文文案排版指北》

出处：https://github.com/sparanoid/chinese-copywriting-guidelines （MIT license）。

- 中文与英文之间、中文与数字之间需要增加空格。
- 使用全形中文标点符号，不与半形标点混用；但遇到完整的英文整句或特殊名词（例如直接引用的英文原句、书名）时，其内容本身使用半形标点。
- 不重复使用标点符号（例如避免连续多个感叹号或问号）。
- 全形标点与其他字符之间不加空格。
