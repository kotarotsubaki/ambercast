This page outlines planned machine-readable resources and the rules governing their availability.

## Availability rule {#availability-rule}

Once generated, `capabilities.json` is the final availability source for agents. Planned pages are excluded from default `llms.txt` and `llms-full.txt`. None of the following resources exists on the live site today; each is planned (not implemented in 0.3.1).

## Planned artifacts {#planned-artifacts}

| Resource | State |
| --- | --- |
| `/ambercast/llms.txt` | planned (not implemented in 0.3.1) |
| `/ambercast/llms-full.txt` | planned (not implemented in 0.3.1) |
| per-locale `/{locale}/llms.txt` variants | planned (not implemented in 0.3.1) |
| `/ambercast/schemas/*.json` | planned (not implemented in 0.3.1) |
| `capabilities.json` | planned (not implemented in 0.3.1) |

Schema artifacts are planned for config, plan, grounding, and report, with identical generated bytes for the site and npm distribution. This page covers build-generated artifacts, with current design plans serving as the sole design source.
