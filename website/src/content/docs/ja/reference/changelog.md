ambercast の各リリースにおける、ユーザーから見える製品の動作変更および公開コントラクトの変更履歴です。破壊的変更（BREAKING）を先頭に配置し、各リリースの変更点を記載しています。

## リリース 0.2.0 {#release-020}

2026-09-04 付の `CHANGELOG.md` リリース 0.2.0 と同期しています。

バージョン 0.2.0 には申告された破壊的変更が1件含まれており、本セクションでは修正内容よりも前に配置しています。

| 区分 | 変更内容 |
| --- | --- |
| BREAKING | プロバイダーリクエストスキーマにおいて `producerBundleFingerprint`、ひいてはすべてのプロンプトの `inputsDigest` が変更されました。すべての 0.1.0 の Plan を再生成してください。`check` は古い Plan を stale として終了コード 4 で報告し、`generate` または `--force` により新しい Plan を作成します。 |
| Fix | 生成処理において、プロバイダーレスポンス内の空の `verificationIntent` を受け入れるようになりました。 |
| Fix | `generate --list` は、生成処理で実際に必要とされない限り、AI プロバイダーを解決しません。 |
| Fix | 人間向けレポート出力において、制御シーケンスがサニタイズされます。 |

## リリース 0.1.0 {#release-010}

2026-09-03 付の `CHANGELOG.md` リリース 0.1.0 と同期しています。

本リリースの記載では、リポジトリのアーキテクチャスキャナー、エージェントフック、ワークツリーのライフサイクル、lint 設定、プロジェクトワークフローのみを変更する changelog エントリを除外していますが、製品の動作や公開コントラクトに関するエントリは漏れなく網羅しています。

| 区分 | 変更内容 |
