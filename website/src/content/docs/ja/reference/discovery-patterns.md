ambercastにおいて設定されたテストファイルの検出（ディスカバリー）におけるマッチングと順序付けの仕様を定義します。ファイルパスの評価には、ワイルドカードとして `*` および `**` のみを持つ専用のパターン言語を使用します。

## パターン言語 {#pattern-language}

| 構文 | 正確な意味 |
| --- | --- |
| `*` | 1つのパスセグメント内における、`/` を除く0文字以上の文字（`[^/]*`）。 |
| `**/` | 0個を含む、0個以上の完全なパスセグメント（`(?:.*/)?`）。 |
| `/` が後続しない `**` | `/` を含む、0文字以上の任意の文字（`.*`）。 |
| その他のすべての文字 | リテラルテキスト。正規表現のメタ文字はエスケープされます。文字クラス、波括弧、extglob、その他の一般的なglob構文に特別な意味はありません。 |
| パターン全体 | マッチングは `^` と `$` でアンカーされ、部分一致は対象外です。 |

実装されている文法には `*` と `**` の2つのワイルドカードトークンのみが存在し、それ以外のすべての文字はリテラルとして扱われます。

## 選択 {#selection}

| 段階 | 規約 |
| --- | --- |
| 包含 | パスは少なくとも1つの `testMatch` パターンにマッチする必要があります。空の `testMatch` は何も選択しません。 |
| 除外 | いずれかの `testIgnore` にマッチするパスは、`testMatch` にもマッチしている場合であっても除外されます。 |
| パス形式 | マッチャーは絶対パスを受け取らず、`testDir` に対する相対的な `/` 区切りのPOSIXパスを受け取ります。 |
| 順序付け | ディスカバリーは非ファイルをスキップし、選択されたパスの重複を排除して、辞書順ソートで返します。 |
| ルート不在時 | `testDir` が存在しない場合は空の選択結果となり、その他のディレクトリ読み取りエラーは `FsIoError` になります。 |

選択されたパスの順序が、これを使用するユースケースに提供される安定した実行順序となります。

## デフォルト値 {#defaults}

| キー | デフォルトパターン |
| --- | --- |
| `testMatch` | `["**/*.test.md"]` |
| `testIgnore` | `["**/.runs/**", "**/*.ambercast.plan.json", "**/*.ambercast.grounding.json"]` |

デフォルト設定では、まず `.test.md` プロンプトを対象に含め、続いて実行ディレクトリと両方のコンパニオン成果物のサフィックスを除外します。

## 具体例 {#worked-examples}

| パターン / 設定 | 候補パス | 結果 | 理由 |
| --- | --- | --- | --- |
| `**/*.test.md` | `login.test.md` | マッチ | `**/` は0個のセグメントにも一致します。 |
| `**/*.test.md` | `nested/checkout.test.md` | マッチ | `**/` は親セグメントを跨ぎます。 |
| `ui/*.test.md` | `ui/auth/login.test.md` | マッチしない | `*` は `/` を跨ぐことができません。 |
| `login.test.md` | `login.test.md.bak` | マッチしない | パス全体が一致する必要があります。 |
| 包含: `**/*.test.md`; 除外: `**/.runs/**` | `nested/.runs/cached.test.md` | マッチしない | 包含判定の後に `testIgnore` が優先されます。 |
| `{login,nested}/*.test.md` | `login/login.test.md` | マッチしない | 波括弧は選択肢の展開ではなく、リテラルとして扱われます。 |
