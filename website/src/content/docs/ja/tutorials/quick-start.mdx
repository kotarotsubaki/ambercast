`npx ambercast init` でプロジェクトを初期化し、`npx ambercast generate` と `npx ambercast run` で最初のテストを動かす。

## 前提条件 \{#prerequisites}

- Node.js 22.14以降が必要
- 認証済みのClaude CodeまたはCodex CLIが必要。最初の`generate`はNode.jsと認証済みプロバイダーを直接必要とする。利用可能なプロバイダーが無い場合のエラーコードは[エラーコード](/ambercast/ja/reference/error-codes/#code-vocabulary)を参照する
- `run`にはChromiumバイナリが必要。生成自体はブラウザードライバーを設定しない

ambercastは次の既定値を使う。

- 既定の`testDir`は`tests/ambercast`
- 既定ターゲットは`web-user`、対象は`http://localhost:3000`、Chromiumを使用

## 手順 \{#steps}

`npx ambercast init` を実行して承認すると、次のファイルが作成される。

- `ambercast.config.json`（既定の`testDir`・`target`を書き込んだ設定ファイル。ファイルの要件は[設定](/ambercast/ja/reference/configuration/#file-selection)を参照）
- `tests/ambercast/find-page.test.md`（サンプルのテストプロンプト）
- `.gitignore`への追記、`AGENTS.md`への追記

作成されるサンプルプロンプトの内容は次のとおり。

```markdown
# Find a page

When I open the application, navigate to the search page, search for "ambercast", and see "Search results".
```

:::caution
`init`はURLを尋ねない。既定の`ambercast.config.json`は`http://localhost:3000`を対象にする。アプリが別のURLで動く場合は、先に`targets.web-user.baseUrl`を書き換える。

:::

<Steps>

1. ## プロジェクトを初期化する \{#init}

   ```bash
   npx ambercast init
   ```

2. ## アプリを起動して計画を生成する \{#generate}

   人またはオペレーターが、設定した`baseUrl`でアプリケーションを起動して確認する。

   ```bash
   npx ambercast generate tests/ambercast/find-page.test.md
   ```

   成功すると次の状態になる。

   - 終了コード`0`、結果ステータス`generated`
   - 生成されたプロンプトの隣に、計画（plan）とグラウンディング（grounding）の2つの派生ファイルが書き出される

   セットアッププロンプト（[エージェント向けセットアップ](/ambercast/ja/agents/setup-prompt/#copy-paste-prompt)）を使うエージェントは、サーバーが既に起動していると想定する。依頼が無い限り自分では起動しない。

3. ## 再生を実行する \{#run}

   ```bash
   npx ambercast run --resolve tests/ambercast/find-page.test.md
   ```

   成功すると次の状態になる。

   - 終了コード`0`
   - 設定したrunsディレクトリの下に、呼び出しごとの`report.json`を作成する

4. ## 変更内容を確認してコミットする \{#review-commit}

   ```bash
   git status --short
   ```

   追跡済みの変更ファイルはすべて`git diff -- <path>`でレビューする。未追跡のprompt・計画・グラウンディングの各パスは、内容全体を確認するか`git diff --no-index /dev/null <path>`を実行する。

   レビュー後、人が3つのファイルをコミットする。初期化で作成された`ambercast.config.json`等も、通常どおり別途レビューしてコミットする。

</Steps>

引数を付けない`npx ambercast generate`と`npx ambercast run`は、設定したテストディレクトリ・マッチ規則・無視規則に一致する全テストを対象にする。このチュートリアルのコマンドは1つの`.test.md`を意図して指定しており、全テストを対象にする操作は別途承認を得たときだけ使う。

## 確認 \{#verification}

- リゾルバーが`tests/ambercast/find-page.ambercast.plan.json`と`tests/ambercast/find-page.ambercast.grounding.json`を作ったことを確認する
- `npx ambercast run --resolve tests/ambercast/find-page.test.md`が終了コード`0`で終わり、対象ケースについて`passed`を報告したことを確認する
