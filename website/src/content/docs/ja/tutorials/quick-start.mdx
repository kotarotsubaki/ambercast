設定ファイルを作らない構成のまま、`npx ambercast generate` と `npx ambercast run` だけで最初のテストを動かす。

## 前提条件 \{#prerequisites}

- Node.js 22.14以降が必要
- 認証済みのClaude CodeまたはCodex CLIが必要。最初の`generate`はNode.jsと認証済みプロバイダーを直接必要とする。利用可能なプロバイダーが無い場合のエラーコードは[エラーコード](/ambercast/ja/reference/error-codes/#code-vocabulary)を参照する
- `run`にはChromiumバイナリが必要。生成自体はブラウザードライバーを設定しない

ambercastは次の既定値を使う。

- 既定の`testDir`は`tests/ambercast`
- 既定ターゲットは`web-user`、対象は`http://localhost:3000`、Chromiumを使用

設定ファイルを置く場合の`$schema`要件は[設定](/ambercast/ja/reference/configuration/#structure)を参照する。このチュートリアルでは設定ファイルを作らない。

## 手順 \{#steps}

設定ファイルは作成せず、次の内容で`tests/ambercast/find-page.test.md`を正確に作成する。末尾の`.test.md`はコンパニオンパス解決の対象になる。

`npx ambercast init`を使うと、同じファイルと最小限の`ambercast.config.json`を一度に生成できる。本チュートリアルは既定値の動作を確認するため、設定ファイルなしの経路を進む。

```markdown
# Find a page

When I open the application, navigate to the search page, search for "ambercast", and see "Search results".
```

<Steps>

1. ## アプリを起動してプランを生成する \{#generate}

   人またはオペレーターが`http://localhost:3000`でアプリケーションを起動して確認した後、`npx ambercast generate tests/ambercast/find-page.test.md`を実行する。

   生成が成功すると終了コード`0`で終わり、結果ステータスは`generated`になる。生成されたプロンプトの隣に、planとgroundingの2つの派生ファイルが書き出される。セットアッププロンプト（[エージェント向けセットアップ](/ambercast/ja/agents/setup-prompt/#copy-paste-prompt)）を使うエージェントは、サーバーが既に起動していると想定し、依頼が無い限り自分では起動しない。

2. ## リプレイを実行する \{#run}

   `npx ambercast run --resolve tests/ambercast/find-page.test.md`を実行する。

   リプレイが成功すると終了コード`0`で終わる。`run`は設定したrunsディレクトリの下に、呼び出しごとの`report.json`を作成する。

3. ## 変更内容を確認してコミットする \{#review-commit}

   `git status --short`を実行し、追跡済みの変更ファイルはすべて`git diff -- <path>`でレビューする。未追跡のprompt・plan・groundingの各パスは、内容全体を確認するか`git diff --no-index /dev/null <path>`を実行する。レビュー後、人が3つのファイルをコミットする。

   エージェントは変更の全体を提示し、会話内で明示的な依頼があったときだけコミットする。CLIフラグや`--yes`はその依頼の代わりにならない（[エージェント向けセットアップ](/ambercast/ja/agents/setup-prompt/#copy-paste-prompt)）。

</Steps>

引数を付けない`npx ambercast generate`と`npx ambercast run`は、設定したテストディレクトリ・マッチ規則・無視規則に一致する全テストを対象にする。このチュートリアルのコマンドは1つの`.test.md`を意図して指定しており、全テストを対象にする操作は別途承認を得たときだけ使う。

## 確認 \{#verification}

- リゾルバーが`tests/ambercast/find-page.ambercast.plan.json`と`tests/ambercast/find-page.ambercast.grounding.json`を作ったことを確認する
- `npx ambercast run --resolve tests/ambercast/find-page.test.md`が終了コード`0`で終わり、対象ケースについて`passed`を報告したことを確認する
