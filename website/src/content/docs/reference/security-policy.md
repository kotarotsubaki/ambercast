This reference details the security maintenance policy and reporting procedures for ambercast.

## Supported versions {#supported-versions}

| Release state | Supported versions |
| --- | --- |
| ambercast is pre-1.0. | Only the latest published version receives fixes. |

Fixes are not promised for older pre-1.0 releases.

## Vulnerability reporting {#vulnerability-reporting}

| Topic | Policy |
| --- | --- |
| Channel | Report privately through GitHub Security Advisories at `https://github.com/kotarotsubaki/ambercast/security/advisories/new`. |
| Required content | Include the affected version, reproduction steps, and impact. |
| Public issues | Do not open a public issue for a security report. |
| Supply chain | The same private channel covers typosquats or impersonation of the `ambercast` npm package. |

See also [Trust and security](/ambercast/explanation/trust-and-security/) and [Contribute](/ambercast/how-to/contribute/).
