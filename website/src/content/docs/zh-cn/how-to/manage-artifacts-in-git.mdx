把提示词、执行计划和定位缓存一起暂存，并让 Git 忽略运行记录目录。

## 前置条件 \{#prerequisites}

默认的定位缓存策略是 `repositoryPolicy: "committed"`。默认的运行记录目录是 `tests/ambercast/.runs`。

## 操作步骤 \{#steps}

<Steps>

1. ## 暂存三个文件 \{#stage-companions}

   策略为 `committed` 时，暂存 `<name>.test.md`、`<name>.ambercast.plan.json` 和 `<name>.ambercast.grounding.json`。解析器定义了这两个相邻的伴生文件后缀。详见[文件布局](/ambercast/zh-cn/reference/file-layout/#companions)。

2. ## 忽略运行证据 \{#ignore-runs}

   把配置的 `runsDir` 添加到 `.gitignore`。使用默认值时，添加下面这一行。

   ```text
   tests/ambercast/.runs/
   ```

   `runsDir` 可以配置。每次运行会在它下面各自的调用目录中写入一份 `report.json`。

3. ## 把定位缓存留在本地 \{#keep-grounding-local}

   如果把定位缓存当作本地缓存，就把 `repositoryPolicy` 设为 `uncommitted`。只有这种情况才需要做这一步和下一步。`$schema` 的值是已发布的配置 Schema URL。

   ```json
   {"$schema":"https://kotarotsubaki.github.io/ambercast/schemas/config.schema.json","grounding":{"repositoryPolicy":"uncommitted"}}
   ```

4. ## 忽略本地的定位缓存 \{#ignore-local-grounding}

   设为 `uncommitted` 后，再把下面这一行添加到 `.gitignore`。如果 `testDir` 与默认值不同，就把 `tests/ambercast` 换成它。

   ```text
   tests/ambercast/**/*.ambercast.grounding.json
   ```

   解析器只在 `testDir` 内部查找定位缓存的伴生文件，并且只认固定后缀 `.ambercast.grounding.json`。因此执行计划仍被追踪，只有本地的定位缓存被忽略。

</Steps>

## 验证 \{#verification}

```bash
git status --short
```

- 策略为 `committed` 时，应看到执行计划和定位缓存的伴生文件。
- 策略为 `uncommitted` 时，应看到执行计划，但看不到 `testDir` 内的 `*.ambercast.grounding.json`。
- 配置的 `runsDir` 已被忽略时，不应看到运行证据。
